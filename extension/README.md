# FirstBid.in — Cross-Browser Extension Installation Guide

This extension is built using **Manifest V3** standard and works natively on all major desktop browsers:
- **Google Chrome**
- **Microsoft Edge**
- **Brave Browser**
- **Opera Browser**
- **Mozilla Firefox** (v109+)

---

## 🚀 How to Install in Chrome, Brave, Edge & Opera

### 1. Google Chrome & Brave:
1. Open your browser and navigate to `chrome://extensions` (or `brave://extensions`).
2. Turn on **Developer mode** toggle in the top-right corner.
3. Click **Load unpacked** button in the top-left corner.
4. Select the `extension` folder inside this project (`/firstbid/extension`).
5. The extension icon ⚡ **FirstBid.in** will appear in your browser toolbar!

### 2. Microsoft Edge:
1. Open Edge and navigate to `edge://extensions`.
2. Enable **Developer mode** in the left sidebar.
3. Click **Load unpacked** and select the `extension` folder.

### 3. Mozilla Firefox (v109+):
1. Open Firefox and navigate to `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on...**.
3. Select the `manifest.json` file inside the `extension` folder.

## ⚙️ Quick Setup & Use on Upwork:

1. Click the ⚡ **FirstBid.in Extension Icon** in your browser toolbar.
2. Paste your **Webhook Token** from your [FirstBid.in Settings](https://firstbidin.com/settings) page and click **Save Settings**.
3. Go to any job post or proposal submission page on **Upwork** (`https://www.upwork.com/jobs/...`).
4. Click the floating **⚡ FirstBid.in Proposal AI** button at the bottom right.
5. Review your 3 Opener Hooks, Cover Letter, and Scope Breakdown, and click **🚀 Auto-Fill Cover Letter Into Upwork** to instantly paste your proposal into Upwork!
